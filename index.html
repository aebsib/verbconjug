📚 Latin Verb Rules

One example per essential rule

1st Conjugation (-āre)
Present Active: Stem + endings
Take present stem (am-) + personal endings: -ō, -ās, -at, -āmus, -ātis, -ant
amō, amās, amat,
amāmus, amātis, amant
2nd Conjugation (-ēre)
Present Active: ē-stem + endings
Stem (habē-) + same endings as 1st (-ō, -ēs, -ēt, -ēmus, -ētis, -ent)
habeō, habēs, habēt,
habēmus, habētis, habent
3rd Conjugation (-ere)
Present Active: Shorten vowel + endings
duc- (from dūcere) + -ō, -is, -it, -imus, -itis, -unt
dūcō, dūcis, dūcit,
dūcimus, dūcitis, dūcunt
Present Passive
Active endings → Passive -r
Replace -ō → -or; others add -r: amatur, amantur
amor, amaris, amatur,
amamur, amaminis, amantur
Imperfect Active (All Conjugations)
Present stem + -bā- + personal endings
1st/2nd/3rd/4th all use same pattern: stem + bā + endings
amābam, amābās, amābat,
amābāmus, amābātis, amābant
Imperfect Passive
Imperfect active + -r endings
Same as active but passive endings (-bar, -bāris, etc.)
amābar, amābāris, amābātur,
amābāmur, amābāminī, amābantur
1st/2nd Conjugation Future
Present stem + -bō
1st/2nd: stem + -bō, -bis, -bit, -bimus, -bitis, -bunt
amābō, amābis, amābit,
amābimus, amābitis, amābunt
3rd/4th Conjugation Future
Future stem (short e) + -am
3rd/4th: dūc- → ducam pattern (like present but -am endings)
dūcam, dūceris, dūcet,
dūcēmus, dūcetis, dūcent
Perfect Active
Perfect stem + -ī
Perfect stem (amāv-) + -ī, -istī, -it, -imus, -istis, -ērunt
amāvī, amāvistī, amāvit,
amāvimus, amāvistis, amāvērunt
Pluperfect Active
Perfect stem + -eram
Perfect stem + imperfect of esse: amāveram pattern
amāveram, amāverās, amāverat,
amāverāmus, amāverātis, amāverant
Perfect Passive
4th principal part + sum
Perfect Passive Participle + present tense of sum
amātus + sum = amātus sum,
amātis + es = amātus es, etc.
